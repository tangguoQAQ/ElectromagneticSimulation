# 计算机电磁模拟和质谱仪简单实现

学过了《高中物理选择性必修第二册》的第一章后，你是否曾对带电粒子在电场磁场中的运行感到好奇？如果能将粒子实时运动的动画展现出来，那些不知如何是好的电磁大题岂不一目了然。带着这样的目的，作者想到粒子运动状态的计算更新和可视化都是计算机擅长的工作，于是便用计算机代码进行模拟，做一个基础的电磁学物理引擎出来，专门解决场中带电粒子的运动模拟，最终运用这个引擎实现简单的质谱仪，以测试其正确性与精准性。

## 项目概况

本项目使用 C++ 17标准，用 Boris 算法进行粒子运动模拟，并使用 Direct2D 进行可视化。

作者使用的编译器是x64 MSVC 14.39.33519，同时项目代码中可能有大量涉及 double 和 float 类型的隐式转换，会抛出很多精度丢失的警告，由于作者时间紧迫，暂时没有全部修补。但这些转换都是和 D2D 相关的可视化部分代码中出现的，而引擎模拟部分全部使用 double 型小数，并不会有太大影响。
